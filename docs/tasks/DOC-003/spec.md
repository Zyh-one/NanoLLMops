# DOC-003：修正专利文档东亚语言与字体映射

## 背景

`发明专利技术交底书-NanoLLMOps-V0.2.docx` 在 WPS 中将中文一级标题显示为 `ＭＳ ゴシック`。检查发现文档主题将东亚语言声明为 `ja-JP`，导致 WPS 采用日文字体分支。

## 目标

- 将文档默认东亚语言和主题东亚语言统一为 `zh-CN`；
- 保留既有标题、正文、图表、页码和页面布局；
- 保留修改前备份；
- 验证 DOCX 压缩包、WordprocessingML 结构和关键字体设置。

## 范围

- 修改桌面上的 `发明专利技术交底书-NanoLLMOps-V0.2.docx`；
- 记录修正过程和验证结果。

## 非目标

- 不改写专利正文；
- 不调整插图内容、图号或章节编号；
- 不处理项目业务代码。

## 验收标准

1. `word/settings.xml` 中 `w:themeFontLang/@w:eastAsia` 为 `zh-CN`；
2. `word/styles.xml` 中默认 `w:lang/@w:eastAsia` 为 `zh-CN`；
3. 一级、二级标题中文字体仍声明为黑体，正文中文字体仍声明为宋体；
4. DOCX 可通过 ZIP 完整性检查，XML 均可解析；
5. 修改前版本有独立备份。
